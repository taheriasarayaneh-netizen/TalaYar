Privacy Policy — TalaYar

What the app accesses. TalaYar requests the Google Drive scope drive.file, which only allows access to files the app itself creates. It cannot see or modify any other file in the user's Drive.

How data is used. The app uploads encrypted database backup files to the owner's own Google Drive and downloads them back for restoration. No data is shared with, sold to, or accessible by any third party. No data is used for advertising.

Storage. Google authorization tokens are stored only on the owner's own server. Backup files are encrypted before upload.

Revoking access. The owner can revoke access at any time at myaccount.google.com/permissions.

TalaYar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

حریم خصوصی — طلایار

طلایار فقط به فایل‌هایی در گوگل‌درایو دسترسی دارد که خودش ساخته است (دسترسی drive.file) و هیچ فایل دیگری را نمی‌بیند. این دسترسی فقط برای ذخیره و بازیابی نسخه‌ی پشتیبان رمزگذاری‌شده‌ی مالک استفاده می‌شود. هیچ اطلاعاتی به شخص ثالث داده یا فروخته نمی‌شود. مالک هر زمان می‌تواند دسترسی را از حساب گوگل خود لغو کند.

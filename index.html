TalaYar (طلایار)

TalaYar is a private gold-shop management application (inventory, sales and accounting) used by a single shop owner. It uses Google Drive only to store the owner's own encrypted database backups.

طلایار یک نرم‌افزار خصوصی مدیریت طلافروشی است و فقط توسط مالک همان فروشگاه استفاده می‌شود. از گوگل‌درایو تنها برای ذخیره‌ی نسخه‌ی پشتیبان رمزگذاری‌شده‌ی خودِ مالک استفاده می‌کند.
